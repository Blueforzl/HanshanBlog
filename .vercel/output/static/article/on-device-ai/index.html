端侧 AI：浏览器里直接跑模型，不调 API

2026-03-18 · Conor Liu
# 端侧 AI：浏览器里直接跑模型，不调 API 浏览器端 AI 推理技术栈与端云混合架构实战指南。 ## 技术栈 ### WebGPU 利用 GPU 加速，在浏览器中高效运行 AI 模型。WebGPU 提供了强大的并行计算能力，适合运行轻量级 AI 模型。 ### ONNX Runtime 跨平台的模型推理框架，支持多种模型格式。可以将训练好的模型转换为 ONNX 格式，在浏览器中运行。 ### WebAssembly 将模型编译为 WASM，提高运行效率。WASM 提供接近原生的性能，适合计算密集型任务。 ## 端云混合架构 ### 本地优先 优先使用本地模型，降低延迟和成本。只有在本地能力不足时才调用云端服务。 ### 云端兜底 在本地能力不足时，自动切换到云端服务。确保用户体验的连续性。 ### 智能调度 根据设备性能和网络状况，智能选择执行方式。动态平衡本地和云端的资源使用。 ## 实战案例 展示如何在实际项目中应用端侧 AI 技术。 ```typescript import { ORT } from 'onnxruntime-web'; // 加载模型 const session = await ORT.InferenceSession.create('model.onnx'); // 准备输入 const input = new ORT.Tensor('float32', data, [1, 3, 224, 224]); // 执行推理 const output = await session.run({ input }); ``` ## 性能对比 | 方案 | 延迟 | 成本 | 隐私性 | |------|------|------|--------| | 纯云端 | 高 | 高 | 低 | | 纯端侧 | 低 | 低 | 高 | | 混合架构 | 中 | 中 | 中 |
